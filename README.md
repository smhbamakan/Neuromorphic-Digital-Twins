# Supplementary code: Neuromorphic Digital Twins (MLWA-D-26-00937, third revision)

All values in Tables 7–11 and Figures 2–4 are regenerated by the commands below. Run them from this folder.
Tested with Python 3.13, Brian2 2.11.0 (Cython code generation), NumPy 2.5.3, SciPy 1.18.1, Matplotlib 3.11.2.

## Section 6.4: two-agent belief tracking (Tables 7–10, Figure 3)

    python scripts/S1_ndt_simulation.py 0 10 results/sim      # seeds 0-9; about 100 s per seed
    python scripts/S2_aggregate_statistics.py results/sim     # summary.json, seed_level.csv, printed tables
    python scripts/S3_make_figure3.py results/sim             # Figure3_minimal_simulation.png

S1 writes one JSON file per seed (all metrics, operation counts, adaptation censoring, interval sensitivity,
robustness sweep) and `traces_seed0.npz` (Figure 3a). The model equations, parameters, weight and delay
distributions, readout and regularisation settings, metric definitions, and the adaptation criterion are
defined in the `CFG` dictionary and the functions of S1. S2 documents the confidence intervals, paired tests,
and Holm–Bonferroni families.

## Section 6.5.5: multi-agent scaling (Table 11, Figure 4)

    python scripts/S4_scaling_simulation.py 0,1,2,3,4 results/scale   # seeds 0-4
    python scripts/S5_scaling_aggregate_figure4.py results/scale      # summary_scale.json, Figure4_measured_scaling.png

S4 contains the social-graph generators (dense, sparse, community, community with rewiring), the partitioning
procedures, and the exact event counting. S5 documents the ratio definitions and the per-seed exponent fits.
